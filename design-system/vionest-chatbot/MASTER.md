# Design System Master File (Light Theme)

> **Project:** Vionest Chatbot
> **Theme:** Light / Clean Corporate
> **Brand Palette:** `#ffffff`, `#2bace2`, `#1b275d`, `#283160`

---

## Color Palette (Light Theme)

| Role | Hex | Usage |
|------|-----|-------|
| Background Principal | `#ffffff` / `#f8fafc` | Fondo de pantalla, canvas de conversación, sidebar |
| Text Primary (Letras) | `#1b275d` | Color principal de lectura, títulos, negritas y respuestas del bot |
| Text Secondary / Details | `#283160` / `#64748b` | Subtítulos, fechas, metadatos y etiquetas |
| Primary / Accent | `#2bace2` | Botones principales, enlaces, bordes activos, badges y spinners |
| Cards / Surfaces | `#ffffff` | Tarjetas de mensajes del bot, modales, inputs |
| Borders | `#e2e8f0` | Líneas divisorias sutiles y bordes de tarjetas |

---

## Components

- **Chat Bubble Bot:** Fondo `#ffffff`, borde `border-slate-200`, texto `#1b275d`, negritas en `#1b275d font-bold`.
- **Chat Bubble User:** Fondo `#2bace2`, texto `#ffffff` en font-semibold.
- **Navbar:** Fondo `#ffffff` con borde inferior `border-slate-200`, logotipo con texto `#1b275d` y acentos en `#2bace2`.
- **Sidebar:** Fondo `#ffffff`, lista de chats con texto `#1b275d`, chat activo resaltado con `#2bace2`.
- **Input:** Fondo `slate-50`, texto `#1b275d`, botón `#2bace2` con icono blanco.
